## 💡 ABOUT SENTINELPAY

SentinelPay is an intelligent payment security and verification platform designed to make digital payment operations safer and smarter.

It provides a centralized dashboard to verify payment requests, manage wallet allowances, monitor transactions, and identify potential security risks.

## ✨ KEY FEATURES

- 🔐 **Payment Verification** – Verify payment requests before authorization.
- 💳 **Wallet Management** – Monitor wallet limits and spending allowances.
- 📊 **Transaction Monitoring** – Track transactions and their statuses.
- 🛡️ **Security Checks** – Identify suspicious payment requests.
- 🤖 **AI-Assisted Analysis** – Support intelligent payment analysis.
- 📈 **Interactive Dashboard** – Monitor payment activities in one place.

## 🔄 HOW IT WORKS

1. A payment request is submitted.
2. The backend checks the request against wallet limits and security rules.
3. The system processes the payment information.
4. A verification decision is generated.
5. Results are displayed on the dashboard.
